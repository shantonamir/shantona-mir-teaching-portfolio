This package contains the full website, all documents added so far, interactive document previews, semester-based student evaluations, professional references, and the three teaching-video descriptions.

TO ADD THE THREE VIDEOS
1. Open the website folder in VS Code.
2. Open assets/videos/.
3. Add the edited MP4 files with these exact names:
   - video-1-scaffolding.mp4
   - video-2-facilitating-group-work.mp4
   - video-3-peer-collaboration.mp4
4. The website automatically changes each video placeholder into an interactive player. No code editing is required.

MAIN WEBSITE FILE
Open index.html locally, or upload/push the whole folder to your GitHub repository.

IMPORTANT
Keep the folder structure unchanged so document previews, images, and videos continue to work.
