Overview

The ELC Academic Vocabulary Learning Platform is a research-informed web application designed to strengthen English vocabulary development for multilingual learners through interactive, personalized, and pedagogically grounded learning experiences.

Unlike traditional flashcard applications, the platform combines corpus-informed vocabulary selection, adaptive learning pathways, contextualized practice, pronunciation support, and instructor management tools to bridge academic English and authentic language use.

The project is currently being developed as a web application with future plans for mobile deployment.

Project Goals

The project aims to:

  • Improve academic vocabulary acquisition for multilingual learners.
  • Bridge general English and academic English through corpus-informed instruction.
  • Personalize vocabulary learning based on learner proficiency and interests.
  • Support instructors through classroom integration and progress monitoring.
  • Develop a scalable platform for English programs and higher education.

Content Sources

The vocabulary database integrates multiple research-based resources, including:

  • Academic Vocabulary List (AVL)
  • Academic Word List (AWL)
  • New Academic General Service List (NAGSL)
  • General Service List (GSL)
  • English Language Center curriculum
  • Discipline-specific vocabulary (planned)
  • Media and authentic language corpora (future extension)

Design Philosophy

The project follows three instructional layers:

Content Layer

Research-based vocabulary selection and lexical information.

Function Layer

  • Presentation
  • Practice
  • Feedback
  • Review
  • Progress monitoring

User Interface Layer

Designed to maximize usability, learner engagement, and long-term retention.
